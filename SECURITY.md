# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately
instead, from the repository's **Security** tab: **Report a vulnerability**
(private vulnerability reporting). The maintainer reads reports there and will
reply through the same thread.

Please include what you found, how to reproduce it, and the Forge version
(Help → About Forge).

## Scope

Forge runs on your computer and starts programs you choose: Python, the
debugger, language servers and the test runner. It can also make web requests
for the API boxes and the OpenAPI clients. Reports about any of these are
welcome, especially ones where a project file or a web response could make
Forge run something or send data it shouldn't.

## Supported versions

Only the latest release gets fixes. Installed copies update themselves
(Settings → Updates); the portable version needs the newer download.
